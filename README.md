# BondCalc CLI (Анализатор портфеля облигаций)

Консольная утилита для расчета текущей доходности позиций портфеля облигаций (ОФЗ и корпоративные бумаги), если их продать сегодня. Программа автоматически подтягивает рыночные цены и историю купонов с API Московской биржи (MOEX), рассчитывает налоговую базу, комиссии и экспортирует результаты в Excel.

## 🚀 Возможности

*   **Чтение покупок из Excel:** Загрузка истории сделок по облигациям.
*   **Интеграция с MOEX ISS API:** Автоматическое получение текущей 'чистой' цены, текущего НКД и истории/графика выплаты купонов для каждой бумаги.
*   **Расчет купонов:** Учет уже полученных купонов после даты покупки лота, расчет комиссий брокера/биржи и расчет НДФЛ с курсовой разницы и выплаченных купонов.
*   **Экспорт в Excel с XIRR:** Формирование отчета на новом листе с автоматической генерацией функции XIRR для расчета годовой доходности.

## ⚙️ Настройка конфигурации (`config.yaml`)

Утилита поддерживает настройку через YAML файл (или использует дефолтные значения). 

```yaml
excel_path: "bonds.xlsx"                  # Путь к файлу портфеля
input_sheet_name: "Sheet1"               # Лист с исходными данными
output_sheet_name: "Sheet1"            # Лист для записи отчета
broker_sell_fee_percent: 0.3              # Комиссия брокера (%)
exchange_sell_fee_percent: 0.085          # Комиссия биржи (%)
tax_rate_percent: 13.0                    # Ставка налога (%)
```

## 📊 Формат входного файла (Excel)

Программа ожидает данные на листе покупок в следующем порядке (строка будет обрабатываться если в первом столбце присутствует дата в соответствующем формате):

1.  **Дата покупки** (формат: `DD.MM.YYYY`, например: `15.01.2024`)
2.  **Название** (Любое пользовательское имя, программно игнорируется)
3.  **SECID** (Строгий код MOEX, например: `SU26238RMFS4`)
4.  **Количество** (шт)
5.  **Сумма покупки** (сумма в рублях за сделку)
6.  **Уплаченный НКД** (сумма в рублях за сделку)
7.  **Комиссия брокера** (сумма в рублях за сделку)
8.  **Комиссия биржи** (сумма в рублях за сделку)


## 💻 Как запустить

Соберите или скачайте готовый бинарный файл под вашу платформу. Создайте excel файл в соответствущем формате и заполните его данными. Создайте файл config.xml, если ваши данные отличаются от значений по умолчанию. Запустите файл, при необходимости указав путь к конфигу через опцию `-c`. Посмотрите готовый отчет в соответстующем листе.
